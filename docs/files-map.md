# フォルダとファイルの地図

採点侍の処理結果は、**選んだ答案画像フォルダの中**に作られる
`_saiten_grading_results`（採点結果フォルダ）にすべて入ります。
**元の答案画像に書き込むことは一切ありません。**

```
答案画像フォルダ/
├─ ○○.jpg …            ← スキャンした答案（触りません）
└─ _saiten_grading_results/
   ├─ 00_Processing/     ← 傾き補正済みの答案画像（作業用）
   ├─ 01_Results/        ← 読み取り結果・正答・設定（採点の元データ）
   ├─ 02_Graded_Detail/  ← 採点済み答案画像（返却用）
   └─ 03_Final_Report/   ← 成績一覧・統計・分析（提出用）
```

## それぞれの役割と「消してよいか」

| フォルダ / ファイル | 役割 | 消してよい？ |
|---|---|---|
| `00_Processing/` | 傾きを補正した答案画像。読み取り・記述採点はこれを使います | △ 消すと読み取りからやり直し |
| `01_Results/` | 読み取り結果（`Mark2-Result-～.xlsx`）、正答・配点（`answer_key.xlsx`）、マーク位置（`coordinates.csv`）、各種設定 | ✕ 採点の元データです |
| `02_Graded_Detail/` | ○×・得点・合計点を描き込んだ答案画像 | ○ いつでも作り直せます |
| `03_Final_Report/` | 成績一覧 Excel・試験統計・分析レポート・R 連携キット | ○ いつでも作り直せます |
| `01_Results/session_state.json` | 中断・再開のための自動保存。次回、同じフォルダを選ぶと「続きから再開しますか？」と確認されます | △ 消すと再開の提案が出なくなるだけ（採点データは無事） |
| `01_Results/descriptive_config.json`<br>`01_Results/descriptive_scores.json` | 記述問題の設定と採点結果 | ✕ 記述採点のデータ本体です |
| `01_Results/tmp_checking_dm_nm.csv` | マーク確認での訂正の下書き（xlsx 反映までの控え） | △ 反映後は消えても問題ありません |
| `01_Results/marker_cache.json` ほか `*_cache.json` | 高速化のためのキャッシュ | ○ 消すと次回すこし遅くなるだけ |

## 中断と再開のしくみ

- 選んだファイルや設定は、操作のたびに `session_state.json` へ**自動保存**されます
- アプリを閉じても、**同じ答案画像フォルダを選び直す**と「前回の続きから再開しますか？」と確認されます
- 起動直後の画面の「前回の採点を再開する」から `session_state.json` を直接選んでも再開できます
- 画面上部の進行バー（準備 → 読み取り → 採点 → 集計）で、どこまで終わっているかをいつでも確認できます

## 画面の言葉と従来の呼び方

| 画面の言葉 | 従来の呼び方 / 実体 |
