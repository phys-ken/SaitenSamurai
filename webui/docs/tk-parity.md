# tkinter 版 ⇔ webui 機能比較表（全ボタン・全操作）

tk 版 GUI の全 UI 要素を棚卸しし、webui との対応を確認した表（2026-08-26）。
凡例: ✅=同等機能あり ／ ◆=形を変えて実現（右欄に方式） ／ ▽=意図的に簡略化 ／ ✕=未搭載

## 起動・モード選択

| tk | 状態 | webui での対応 |
|---|---|---|
| StartupModeDialog（5モードカード） | ✅ | モード選択画面（同5カード） |
| 採点再開（セッション復元） | ✅ | 「前回の採点を再開する」 |
| クラッシュ時のエラーダイアログ＋ログ | ◆ | bridge 例外は各応答の error として画面ログに出る |

## メイン画面 — データソース／オプション

| tk | 状態 | webui |
|---|---|---|

| 座標ファイル選択＋即時チェック | ✅ | 選択時に行数/マーク数を要約、モード不一致は⚠表示 |
| Skip 入力＋ツールチップ | ✅ | Skip 欄（title 属性で説明） |
| 正答データ選択＋自動チェック | ✅ | 選択時に answer_key_checker 自動実行・結果を常時表示 |
| 正答データの自動検出（フォルダ選択時） | ✅ | 同じ（01_Results/answer_key.xlsx を自動設定） |
| 📋 正答チェック（手動再実行＋md出力） | ✅ | 「再チェック」ボタン |
| OMR結果の手動選択 | ✅ | 同（認識実行で自動設定も同じ） |
| 認識方式コンボ（クラスタリング/しきい値） | ✅ | 同 |

| 📂 前回の状態を復元（メイン画面から） | ✅ | フォルダ選択時にセッション検出→復元を提案（tk の自動提案と同じ）。モード選択画面からも可 |
| パスの修復ダイアログ | ◆ | 壊れたパスは警告としてログに出し、通常の選択ボタンで選び直す |

| チェック8種（正答番号/○×/得点/観点/★/白塗り/満点/観点行） | ✅ | 同一8種＋説明文つき（★は「不適切問題の救済用」と明示） |
| 記述: 透過率スライダー＋チェック3種 | ✅ | 同（濃さは数値入力 0〜1） |
| オフセット ◀◀◀◀·/·▶▶▶▶ ステッパー | ✅ | 同じ7ボタン構成（±1/±0.5/±0.1） |
| 📐 位置プレビュー（矩形表示） | ◆ | 実際の描画関数で正解/不正解/★の3例を描くライブプレビュー（全トグル・白塗り・オフセットが即反映。tk の矩形より情報が多い） |

| 適用/キャンセル | ◆ | 変更は即保存（キャンセル概念なし。既定に戻すで復帰） |

## 記述採点（採点・確認）

| tk | 状態 | webui |
|---|---|---|
| 採点モード選択（1枚ずつ/一覧） | ✅ | 「記述採点」グリッド＋「一枚ずつ採点する」 |
| 一覧: 得点ボタン→サムネクリック連続付与 | ◆ | カーソル＋数字キー自動送り（クリックでも可） |
| キー: 0-9 / m / b / Space / Del / ←→ / Tab | ✅ | 0-9・m（満点）・b（0点）・BackSpace・Space（次へ）・←→↑↓・「次の未採点へ」ボタン（Tab はボタン化） |
| 配点10点以上の数値入力 | ✅ | 2桁バッファ（500ms確定/Enter） |
| ズーム（1枚ずつ 25-300% / 一覧 80-800px） | ◆ | 一枚採点: Ctrl+ホイール自由ズーム＋パン／グリッド: サイズ選択＋クリック拡大 |
| 未採点のみフィルタ | ✅ | 表示フィルタ（全て/未採点/満点/0点/中間点） |
| 並び順（ファイル名/得点昇降/白さ） | ◆ | ファイル名/得点昇降（白さ順は記述クロップには未対応） |
| 得点による色分け（青/赤/橙） | ▽ | 採点済みは朱の得点表示・フィルタで抽出（配色は赤ペンデザインに統一） |
| 統計（採点済/平均） | ✅ | タブ集計＋「この問題の平均」表示 |
| 📷 元画像を開く | ✅ | 一枚採点「元画像を開く」 |
| 入力可能得点の制限チェック（0-9個別ON/OFF） | ✕ | ニッチのため未搭載（要望があれば追加） |
| 全件完了ダイアログ／未採点確認 | ✅ | ログ通知＋採点/集計前の未完了確認 |
| 設定変更（問題名/配点/観点、採点リセット、配点キャップ） | ✅ | 設定表でその場編集（配点を下げた場合の超過得点キャップも同じ）＋「採点リセット」ボタン |

## tk 側にあるが UI から到達不能（比較対象外）

- `run_generate_return_sheets`（ボタン廃止済み）／「記述問題も採点する」チェック（pack されない）
- キャリブレーターの「詳細設定（テスト読み取り）」（ウィジェット未生成）
- 旧ウィザード方式の記述設定（`setup_descriptive_regions`）
