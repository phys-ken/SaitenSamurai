# マーク＋記述の使い方

マーク式と記述式が混在する試験を、1 つの流れで採点するモードです。
マーク部分は自動で読み取り、記述部分はキーボード採点で処理し、
最後に**合計点が自動で合算**されます。

このページは **新UI（v5 系ベータ）** の画面で説明します。
従来UI（v4 系）をお使いの場合は、各所の「従来UI」タブをご覧ください。

マーク部分・記述部分それぞれの詳しい操作は
[マーク採点の使い方](mark.md) / [記述式採点の使い方](descriptive.md) と共通です。
このページでは**通しの流れ**と、**混在モードならではの点**に絞って説明します。

---

## 全体の流れ

```
ファイルを読み込む → ▶ 答案を読み取る → 正答・配点を入力 → マークを確認する
  → 記述問題の設定 → 記述を採点する
  → ▶ 採点済み答案を生成 → ▶ 集計してまとめる
```

モード選択画面では **「マーク採点 ＋ 記述採点」** カードを選びます
（共通テスト数学式なら「数学マーク採点 ＋ 記述採点」）。

---

## マーク部分を読み取る

1. **答案画像フォルダ**の「フォルダ選択」でスキャン画像のフォルダを、
   **マーク位置の定義**の「ファイル選択」で Mark2 の座標 Excel を選び、
   **ID欄の列数**を確認します（Mark2 標準テンプレートは 4）
2. **「▶ 答案を読み取る」** を押します — 傾き補正とマークの読み取りが行われ、
   記述採点用の画像もここで一緒に準備されます
3. 自動生成された `01_Results/answer_key.xlsx` に**正答・配点・観点**を記入し、
   **正答・配点**の「ファイル選択」で選びます
4. **「マークを確認する」** で無記入・二重マークなどを確認・訂正します（推奨）

ここまでの操作は [マーク採点の使い方](mark.md) /
[クイックスタート](../quickstart.md) と同じです。

---

## 記述部分を設定して採点する

メイン画面の **② 採点する** に、記述用のボタンが 2 つ表示されています。
ボタン横には「N 問 / 採点済み x / y」の進捗が常に出ます。

1. **「記述問題の設定」** — 問題名・配点・観点を入力して
   **「＋ 領域を指定して追加」** → 答案上をドラッグ。変更は即時保存されます
2. **「記述を採点する」** — 問題別グリッドで数字キー採点。
   1 人分を通して見たいときや手書きコメントは **「一枚採点へ」**

操作の詳細（キーボード採点・フィルタ・手書きコメント）は
**[記述式採点の使い方](descriptive.md)** をご覧ください。

---

## 混在モードならではの点

### 合計点はマーク＋記述の合算です

**「▶ 採点済み答案を生成」** で答案に描かれる合計点も、
**「▶ 集計してまとめる」** の成績一覧も、
マーク部分と記述部分の得点を**自動で合算**した値になります。
合計点を描く場所は「出力の設定」の **「合計点の位置」** で指定できます。

### 記述採点の結果を分析に含めるかを選べます

**「出力の設定」** の **「分析の範囲」** に
**「記述採点の結果を分析ファイルに含める」** チェックがあります
（マーク＋記述モードでのみ表示・既定でオン）。
オフにすると、CTT 分析などの分析レポートはマーク部分だけを対象にします。
成績一覧の合計点には、どちらでも記述の得点が含まれます。

### 記述が未採点のまま進もうとすると確認されます

記述の採点が終わらないうちに「▶ 採点済み答案を生成」や「▶ 集計してまとめる」を押すと、

> 記述採点が完了していません（採点済み x / y）。
> 未採点の問題は 0点 として扱われます。このまま続行しますか？

という確認が表示されます。続行もできますが、**未採点は 0 点として集計される**ため、
先に採点を終えることをおすすめします。

---

## 出力される場所

すべての出力は、答案画像フォルダ内の `_saiten_grading_results/` に入ります。

```
答案画像フォルダ/
└─ _saiten_grading_results/
   ├─ 00_Processing/            ← 傾き補正済みの答案（作業用）
   ├─ 01_Results/               ← 読み取り結果・正答・記述の設定と採点・handwriting.json
   ├─ 02_Graded_Detail/         ← 採点済み答案画像（マーク＋記述＋手書きを描画）
   └─ 03_Final_Report/          ← 成績一覧・統計・分析（提出用）
```

各フォルダの意味と「消してよいか」は
**[フォルダとファイルの地図](../files-map.md)** にまとまっています。

---

## 中断と再開

混在モードは作業量が多くなりますが、途中保存の操作は要りません。

- 選んだファイル・設定・採点結果は**操作のたびに自動保存**されます
- 作業を再開するときは、**同じ答案画像フォルダを選び直す**と
  「前回の続きから再開しますか？」と提案されます。
  モード選択画面の **「前回の採点を再開する」** からも再開できます

詳しくは [中断と再開のしくみ](../files-map.md#resume) をご覧ください。

=== "従来UI"

    従来UIでは、記述採点は問題一覧画面の**採点モードプルダウン**と各問題の
    「採点」ボタンで行い、最後に「✔ 採点完了・保存」で保存します。
    新UIではこれらは廃止され、グリッド画面のタブ切替と即時保存に統合されています。
    採点データは両UIで完全に共通なので、途中でどちらへ移っても続きから採点できます。
