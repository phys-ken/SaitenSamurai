# 記述式採点の使い方

答案上の記述欄をドラッグで指定し、キーボード中心の操作で効率よく採点するモードです。
マーク位置の定義（座標ファイル）は不要で、スキャン画像だけで始められます。

このページは **新UI（v5 系ベータ）** の画面で説明します。
従来UI（v4 系）をお使いの場合は、各所の「従来UI」タブをご覧ください。

このページの内容は、**記述採点のみ**モードだけでなく、
**マーク採点 ＋ 記述採点**モードの記述部分にもそのまま当てはまります
（[マーク＋記述の使い方](combined.md)）。

---

## 全体の流れ

```
答案画像フォルダを選ぶ → ▶ 画像を準備する → 記述問題の設定
  → 記述を採点する（一覧グリッド / 1枚ずつ）
  → 答案ごとの確認・修正（手書きコメント）
  → ▶ 採点済み答案を生成 → ▶ 集計してまとめる
```

---

## 事前準備

必要なのはスキャン画像だけです。

| 必要なもの | 説明 |
|---|---|
| **スキャン画像** | 答案をスキャンした JPEG / PNG / PDF。**1 枚の画像 = 1 人分の答案** です |

!!! tip "スキャン時のポイント"
    - 解像度は **200〜300 dpi** がおすすめです
    - コーナーマーカーがある場合は、傾き補正が自動で行われます
    - 普通のコピー機の「スキャン → フォルダ保存」機能で十分です

!!! info "ファイル名が生徒名になります"
    ファイル名がそのまま集計シートの「生徒ID」として使われます。
    `01_山田太郎.jpg`、`02_鈴木花子.jpg` のように、生徒名を含めたファイル名にしておくと便利です。

---

## 画像を準備する

1. モード選択画面で **「記述採点のみ」** カードを選びます
2. **答案画像フォルダ**の「フォルダ選択」で、スキャン画像のフォルダを指定します
   （PDF の場合は「PDF選択」— 自動で画像に展開されます）
3. **「▶ 画像を準備する」** を押します — 全答案の傾きを補正し、採点用の画像が
   `00_Processing` フォルダに用意されます

選んだフォルダや設定は**操作のたびに自動保存**されます。保存ボタンはありません。

=== "マーク＋記述モードの場合"

    マーク採点 ＋ 記述採点モードでは、**「▶ 答案を読み取る」** が画像の準備を兼ねます。
    マークの読み取りが終わっていれば、そのまま記述の設定・採点に進めます。

---

## 記述問題の設定

メイン画面の **② 採点する** にある **「記述問題の設定」** を押すと、設定画面が開きます。

1. 画面下部の入力欄に **問題名**（例: 問3）・**配点**・**観点** を入力します
2. **「＋ 領域を指定して追加」** を押します — 答案画像が表示されるので、
   その問題の解答欄を **マウスでドラッグ** して囲みます
3. 問題の数だけ手順 1〜2 を繰り返します

追加した問題は表に並びます。表の上でそのまま編集・操作できます。

| 操作 | 内容 |
|---|---|
| **名前 / 配点 / 観点の欄** | その場で書き換えられます（変更した瞬間に保存されます） |
| **領域再指定** | 答案上でドラッグし直して、採点領域を描き直します |
| **採点リセット** | その問題の採点データをすべて消します（確認あり・取り消し不可） |
| **削除** | 問題そのものを削除します（採点済みの得点も消えます） |

!!! info "配点を下げたときは自動で丸められます"
    採点を始めた後に配点を下げると、新しい配点を超えている得点は
    **自動的に新配点に丸められ**、何件丸めたかが処理ログに表示されます。

変更はすべて**即時保存**されます。OK ボタンはありません。
設定が済んだら **「閉じる」** でメイン画面に戻ってください。

=== "従来UI"

    従来UIの統合セットアップ画面では順序が逆で、**先に答案上をドラッグ**すると
    右側のテーブルに行が追加され、問題名・配点・観点を**ダブルクリックで編集**し、
    最後に **「OK」** で確定します。新UIには OK ボタンはなく、即時保存です。

## 記述を採点する（問題別グリッド）

メイン画面の **「記述を採点する」** を押すと、問題ごとに全員の解答を
一覧表示するグリッド画面が開きます（ボタン横に「N 問 / 採点済み x / y」の進捗が出ます）。

![記述採点のグリッド画面](../images/webui/07_desc_grid.png){ .screenshot }
<span class="caption">記述採点の問題別グリッド — 朱色の枠が採点カーソル。数字キーを押すと採点して次の未採点へ進みます</span>

- 上部の**問題タブ**で問題を切り替えます。タブには「問1 (採点済み/枚数)」の形で
  進捗が表示され、ヘッダには**その問題の平均点**も表示されます
- 朱色の枠（採点カーソル）が「いま採点している答案」です。
  **数字キーを押すだけで得点が付き、自動で次の未採点へ進みます**

### キーボード操作

| キー | 操作 |
|---|---|
| `0`〜`9` | 得点を入力して、自動で次の未採点へ |
| `m` | 満点にする |
| `b` | 0 点にする |
| `Space` | 採点せずに次へ |
| `BackSpace` | 未採点に戻す |
| `←` `→` `↑` `↓` | カーソル移動 |

!!! tip "配点が 10 点以上の場合 — 2桁入力"
    数字キーを続けて押すと 2 桁の得点として扱われます（例: `1` → `2` で 12 点）。
    キーを止めて **0.5 秒**経つか、`Enter` を押すと確定します。

マウス派の方は、上部の **「クリックで付ける得点」** で点数を選んでから
カードをクリックすると、その得点が付きます。
カードを**ダブルクリック**すると、その答案から「1枚ずつ」表示に切り替わります。

### 表示の絞り込みと並べ替え

| コントロール | 選択肢 |
|---|---|
| **次の未採点へ** | 次の未採点答案までカーソルをジャンプ |
| **表示** | 全て / 未採点 / 満点 / 0点 / 中間点 |
| **並び順** | ファイル名順 / 得点 昇順 / 得点 降順 |
| **カード** | 小 / 中 / 大 |

採点後の見直しは、**表示を「中間点」や「0点」に絞る**と効率的です。

!!! info "採点は 1 打ごとに保存されます"
    採点結果はキーを押すたびに `01_Results/descriptive_scores.json` に保存されます。
    「採点完了」のような確定ボタンはなく、いつ閉じても大丈夫です。

### 1枚ずつ採点する

グリッド画面右上の **「一覧 / 1枚ずつ」** 切り替えで、従来UIと同じ
**1枚ずつモード**に切り替えられます。同じ問題の解答を 1 枚ずつ大きく表示し、
**数字キーを押すだけで採点して次の答案へ**進みます。細かい字を読みながら
テンポよく採点したいときはこちらが便利です。

- キー操作は一覧と共通です（数字・`m`・`b`・`Space`・`BackSpace`・`←` `→`）
- `Ctrl` + ホイールで拡大・縮小できます
- 表示の絞り込み・並べ替えも一覧と共通で、カーソル位置を保ったまま
  いつでも「一覧」に戻れます

=== "従来UI"

    従来UIでは、問題一覧画面の上部プルダウンで**採点モード（1枚ずつ / 一覧）**を選び、
    各問題の「採点」ボタンで採点ウィンドウを開き、最後に「✔ 採点完了・保存」で保存します。
    新UIでは同じ画面右上の切り替えで、保存操作なし（1打ごとに自動保存）で使えます。
    並び順の「画像の白さ順」（空欄の答案を先頭に集める）は従来UIのみの機能で、
    新UIでは表示フィルタ「未採点」がその役割を担います。

## 答案ごとの確認・修正と手書きコメント { #single-sheet }

メイン画面の **② 採点する** にある **「答案ごとの確認・修正」** を押すと、
答案の一覧（1 人 = 1 行、採点状況と手書きの有無つき）が開きます。
答案を選ぶと、その 1 枚を丸ごと表示して確認する画面に切り替わります。
**採点済みの答案を 1 人分ずつ見直したいとき**や、
**答案に手書きのコメントを書きたいとき**はこちらを使ってください。

![答案ごとの確認・修正と手書きコメント](../images/webui/08_single_handwriting.png){ .screenshot }
<span class="caption">答案ごとの確認・修正 — 答案上に記述領域の枠と得点が重なり、右側のパネルまたはキーで採点。朱色の線は手書きコメント</span>

答案上には各問題の領域枠と得点が表示され、右側のパネルに問題別の得点ボタンが並びます。
採点キーはグリッドと同じ（数字・`m`・`b`・`BackSpace`）で、
採点すると**同じ答案の次の未採点問題**へ、全問済みなら**次の答案**へ自動で進みます。

### 移動と表示

| 操作 | 内容 |
|---|---|
| `←` `→`（◀ 前の答案 / 次の答案 ▶） | 答案を送る |
| `↑` `↓` | 採点対象の設問を切り替える |
| **未採点の答案へ** | 未採点が残っている次の答案へジャンプ |
| `Ctrl` + ホイール | カーソル位置を中心に拡大・縮小 |
| ドラッグ | 表示位置を移動 |
| **幅に合わせる** / **原寸** | 表示倍率をリセット |
| **元画像を開く** | 補正前のスキャン原本を OS の画像ビューアで開く |

### 手書きコメント

答案ごとの確認・修正の画面では、答案に直接コメントを手書きできます。

- **ペン（ペンタブレット・スタイラス）はいつでもそのまま書けます**。
  筆圧に応じて線の太さが変わります
- **マウスで書くときは「✎ コメント」**（キー `C`）をオンにします。
  オフのときはドラッグ＝表示移動のままです

| ツール | 内容 |
|---|---|
| **色** | 朱 / 青 / 墨 |
| **太さ** | 細 / 太 |
| **消しゴム** | なぞったストロークを**ひと筆単位**で消します |
| **戻す / やり直す** | `Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z` でも可） |
| **全消去** | この答案の手書きをすべて消します（確認あり） |

!!! info "元の答案は汚しません — 何度でも書き直せます"
    手書きの筆跡は画像に直接描かれるのではなく、
    `01_Results/handwriting.json` に**線のデータとして自動保存**されます
    （ズームしてもにじみません）。答案画像への焼き込みは
    **「▶ 採点済み答案を生成」** を押したときに、出力用の画像
    （`02_Graded_Detail`）へ合成されます。**元のスキャン画像には一切書き込まない**ので、
    後から何度でも書き直して作り直せます。

!!! tip "マーク採点のみモードでも手書きできます"
    マーク採点のみのモードでも、同じ **「答案ごとの確認・修正」** から
    コメント専用（採点パネルなし）の画面が開きます。

「答案一覧に戻る」で答案の一覧へ、「閉じる」でメイン画面に戻れます。

## 出力と集計

採点が終わったら、メイン画面に戻って
**「▶ 採点済み答案を生成」→「▶ 集計してまとめる」** の順に押します。
手順の詳細は [クイックスタート](../quickstart.md) と同じです。

描き込みの内容を変えたいときは、**「出力の設定」** を開いてください。

- **表示項目の設定** — 記述領域に描く ○×△・得点・観点と、**描き込みの濃さ（0〜1）**
- **合計点の位置** — 合計点を答案のどこに描くかをドラッグで指定
- **氏名画像を表示する ＋ 氏名欄の位置指定** — 集計シートに氏名欄の画像を貼る

!!! info "○×△ は得点から自動で決まります"
    満点 → ○、0 点 → ×、それ以外（中間点）→ △ として描画されます。

!!! warning "未採点が残っていると 0 点扱いになります"
    未採点のまま生成・集計しようとすると
    「未採点の問題は 0点 として扱われます」という確認が表示されます。
    続行もできますが、先に採点を終えることをおすすめします。

出力はすべて、答案画像フォルダ内の `_saiten_grading_results/` に入ります。
各フォルダの意味は **[フォルダとファイルの地図](../files-map.md)** をご覧ください。
